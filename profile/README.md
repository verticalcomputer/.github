## Start with Sherlock

**Observability and investigation for GPU clusters.**

Sherlock collects scoped evidence, evaluates deterministic conditions, and preserves incident and investigation history. Built in Go with PostgreSQL, it makes the evidence behind an investigation explicit and traceable.

**Experimental** · Go / PostgreSQL · Apache-2.0

The resident agent and cluster-local gateway are under active development. See the [current implementation status](https://github.com/verticalcomputer/sherlock/blob/main/next.md) for supported sources and release readiness.
