# Vertical on GitHub

Public organization profile for [Vertical](https://github.com/verticalcomputer).

- [`profile/README.md`](profile/README.md) is the organization homepage.
- [`profile/assets/`](profile/assets/) contains the desktop and mobile banners.
- Brand artwork and usage guidance: [vertical.computer/brand](https://vertical.computer/brand).

The banners use Vertical's supplied wordmark, Switzer type, orange `#F54819`, ink `#151515`, and white `#FFFFFF`. The wordmark artwork is preserved without modification.
